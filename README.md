# Milk Quest: Half & Half
This codebase is for the cancelled Milk Quest: Half & Half game. This game was also the base for [Milk Quest: Milk & Cookies](https://stevethebartender.itch.io/milk-quest-christmas). Milk & Cookies was originally built inside of Half & Half during the end of 2020, with the rest of the game's development being done on top of Milk & Cookies. Later, in 2022, Milk & Cookies was remastered and rereleased with the Half & Half content gutted out.
The 'Master' branch contains the code and full version history for Milk Quest: Half & Half, while the 'christmas' branch contains the code for the 2022 rerelease of Milk Quest: Milk & Cookies. You'll need GameMaker Studio 2 to build it. The code may require some changes in order to run properly on modern versions of the engine.
If you are interested in a more modern version of this code, check out [Milk Quest: Repasteurized](https://milkquest.org/games.html) when it releases, as the game is a fork of this code.
